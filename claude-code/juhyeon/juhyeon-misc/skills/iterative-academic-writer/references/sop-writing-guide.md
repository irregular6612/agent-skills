# SoP / 학업계획서 Writing Guide

논문(Paper)·제안서(Proposal)와의 차이를 먼저 인식한다. 동일한 25원칙을 적용하되 수사 목표와 독자가 다르다.

| 항목 | Paper | Proposal | SoP |
|------|-------|----------|-----|
| 독자 | 동료 심사자 | 인접 분야 심사위원 | 입학사정관 (분야 외부 포함) |
| 시제 | 과거·현재 | 미래 | 과거(역량)→현재(전환)→미래(목표) 혼합 |
| 핵심 설득 | 결과 유효성 | 계획 가치 | 후보자 적합성 |
| 주요 증거 | 실험 결과 | 예비 결과·팀 역량 | 본인 활동 결과·재현 가능한 기여 |
| 실패 모드 | Hallucination | 측정 불가 목표 | 추상 자기 묘사, 일관 없는 narrative |
| IS1 적용 | 기법 동기 | 접근법 선택 이유 | 진로 결정의 인과 (왜 이 분야→왜 이 program) |

---

## SoP 전용 추가 원칙 (SoP1–SoP5)

25원칙 외 SoP에만 적용. Critic subagent에 함께 전달.

| ID   | 원칙                       | 위반 예시 |
|------|----------------------------|-----------|
| SoP1 | **Narrative arc**          | "I am passionate about X. I worked on Y. I want Z." — 인과 없는 병렬 |
| SoP2 | **Specific evidence**      | "강한 문제 해결 능력" — 측정/재현 가능한 evidence 부재 |
| SoP3 | **Fit signal**             | 지원 program/lab 언급 없이 일반 진술 |
| SoP4 | **Future-back reasoning**  | 미래 목표가 과거 경험과 인과적으로 미연결 |
| SoP5 | **First-person grounding** | "팀이 X를 했다" — 본인 기여 모호 |

## 구조 (한국형 학업계획서 vs 국제형 SoP)

### 한국형 학업계획서 (대학원 진학)
1. **지원 동기** (1문단) — 두괄식: "X 분야에서 Y 문제 해결을 위해 본 프로그램에 지원한다"
2. **학업 배경 및 역량** (1–2문단) — 구체 evidence (학점, 프로젝트, 인턴, 논문, 결과 수치)
3. **연구·학업 계획** (1–2문단) — SMART 목표 + 지도교수·연구실 fit
4. **장기 비전** (1문단) — 과거→현재→미래 인과 체인

### 국제형 SoP (PhD/Master's)
1. **Opening anchor** (1문단) — 구체적 일화·문제 + Why this field
2. **Research preparation** (2–3문단) — 각 경험에 "What I did / What I learned / Why it matters"
3. **Fit & specific research interests** (1–2문단) — 교수명·랩명·구체 논문 인용
4. **Future goals & closing** (1문단) — 단기/장기 목표 + 본 program이 필수인 이유

## Blueprint 자체 검증 — SoP 추가 항목

Phase 1 Blueprint 작성 후 다음을 추가 확인:

| 항목 | 요건 |
|------|------|
| Narrative arc(과거→현재→미래)이 인과로 연결되는가? (SoP1) | ✅/❌ |
| 각 강점·역량에 specific evidence가 있는가? (SoP2)        | ✅/❌ |
| 지원 program/lab/교수 언급이 있는가? (SoP3)              | ✅/❌ |
| 미래 목표가 과거 경험과 인과적으로 연결되는가? (SoP4)    | ✅/❌ |
| 모든 활동에 First-person 기여가 명확한가? (SoP5)         | ✅/❌ |

**재작성 임계값**: SoP 항목 1개라도 미충족 시 즉시 재작성 (SoP1·SoP3은 합격 가능성에 직결).

## 흔한 함정

| 함정 | 설명 | 대응 |
|------|------|------|
| "관심이 많다" 류 | 동기가 추상적 — evidence 없음 | SoP2 + 구체 일화 |
| 활동 나열만 | 학습·기여·의미 분석 부재 | What I did/learned/why 구조 |
| 일반화된 program 진술 | 어느 학교에든 보낼 수 있는 SoP | SoP3 + 교수·랩 specific 인용 |
| 과거형 일관 부재 | "X를 했다"와 "X를 할 것이다" 혼용 무논리 | 시제 분기 명확화 |
| 추상 형용사 | "혁신적인", "독창적인" 자기 표현 | NL2 + 결과 수치로 대체 |
