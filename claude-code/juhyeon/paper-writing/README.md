# paper-writing

Polishing and sharing academic prose. No subagents, no hooks.

- `paper-section-rewrite` — 4-level critic loop over a single section
  (content → inter-paragraph → intra-paragraph → sentence), with an
  ML-beginner readability gate and a notation audit. KO/EN.
- `paper-readability-review` — renders reviewer annotations onto a PDF.
- `paper-digest` — insight-first single-paragraph summary for Discord, Slack
  or Twitter.
