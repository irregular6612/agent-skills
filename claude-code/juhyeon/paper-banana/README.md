# paper-banana

Publication-quality diagrams and plots through the bundled `paperbanana` MCP
engine under `skills/paper-banana/engine/`.

The engine needs its own `.env`; copy `engine/.env.example` and fill it in. The
real `.env` is excluded by the repository `.gitignore` and must never be
committed.

Generated figures land in `engine/outputs/`, which is also excluded.
