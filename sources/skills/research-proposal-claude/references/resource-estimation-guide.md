> **주의**: AWS/GCP 가격은 인스턴스 단위 (GPU 8개 포함)이므로, GPU 1개 기준 가격이 아님.

### 비용 추정 공식

```
총 비용 = GPU 수 × 시간당 가격 × 총 학습 시간 × (1 + 여유 계수)

여유 계수:
  - 안정적 환경 (Lambda/RunPod): 0.2
  - 불안정 환경 (spot instance): 0.5
  - 디버깅 포함: 1.0-2.0
```

## 4. 시간 추정 가이드

### 연구 단계별 소요 시간 (참고 범위)

| 단계 | 최소 | 일반적 | 최대 | 비고 |
|------|------|--------|------|------|
| 문헌 조사 | 1주 | 2-3주 | 6주 | 논문 수에 비례 |
| 데이터 수집/전처리 | 1주 | 2-4주 | 8주 | 데이터 유형에 따라 큰 편차 |
| 실험 설계/파일럿 | 1주 | 1-2주 | 3주 | 파일럿 결과에 따라 설계 수정 |
| 본 실험 | 1주 | 2-4주 | 12주 | GPU/실험 조건 수에 비례 |
| 결과 분석 | 1주 | 1-2주 | 4주 | 통계/시각화 복잡도에 따라 |
| 논문 작성 | 2주 | 4-6주 | 12주 | 학회/저널 형식에 따라 |
| 리비전 | 1주 | 2-4주 | 8주 | 리뷰어 피드백에 따라 |

### 실험 시간 추정 공식

```
단일 실험 시간 = 데이터 로딩 + (epoch 수 × epoch 당 시간) + 평가 시간

총 실험 시간 = Σ (독립변수 조합 수 × 반복 횟수 × 단일 실험 시간)

예시:
  - 독립변수 1: 3 수준, 독립변수 2: 4 수준 → 12 조합
  - 반복: 3회 (seed)
  - 단일 실험: 2시간
  → 총: 12 × 3 × 2 = 72시간 = A100 1대 기준 약 3일
```

## 6. 비용 절감 팁

1. **Spot/Preemptible 인스턴스**: 최대 70% 절감, 단 체크포인팅 필수
2. **Mixed Precision Training**: FP16/BF16으로 학습 시간 30-50% 단축
3. **Gradient Accumulation**: 작은 배치를 누적하여 큰 배치 효과, VRAM 절약
4. **QLoRA/LoRA**: Full fine-tuning 대비 VRAM 75-90% 절약
5. **Early Stopping**: 불필요한 학습 시간 절약
6. **Progressive Training**: 작은 모델로 하이퍼파라미터 탐색 후, 큰 모델에 적용

## 7. 예산 정당화 가이드 (Budget Justification Guide)

### 예산 정당화 원칙

1. **구체성**: 모든 비용 항목에 산출 근거를 명시 (GPU 유형 × 시간 × 단가)
2. **필수성**: 각 항목이 연구에 왜 필수적인지 1-2문장으로 설명
3. **대안 검토**: 더 저렴한 대안이 부적합한 이유를 기술
4. **여유 계수**: 예상치 못한 비용을 위해 10-20% 버퍼 포함
