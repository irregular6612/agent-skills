# 템플릿

사용자가 학교·학회·연구실 템플릿(.pptx/.potx)을 주면 `kit/template.py`로 읽어 덱에 입힌다. 없으면 기본 스타일 그대로.

```bash
python3 ~/.claude/skills/research-deck/kit/template.py <template.potx> <talk>/build
```

## 가져오는 것

- 슬라이드 크기: 16:9만. 10 × 5.625 in 같은 다른 16:9 크기는 13.333 × 7.5로 비례 확대. 4:3이면 멈추고 16:9 판을 요청한다.
- 테마 색: `dk1` → 글자, 대비 3:1 이상인 첫 accent → 강조색(`T.accent`, 흐림 위 강조 박스·현재 단계·원장 칩), 그다음 accent → `T.accent2`.
- 테마 글꼴: minor → 본문, major → 제목. 이 기기에 없으면 LibreOffice 렌더가 대체 글꼴로 나온다 (설치하거나 사용자에게 알린다).
- 마스터 + 레이아웃 두 개를 pptx 마스터로: `TITLE`(제목 없는 장: 제목 슬라이드·질문 표지), `CONTENT`(나머지). 배경(색·이미지), 자리표시자가 아닌 그림·사각형·선·글자.
- 제목 자리표시자 위치·색 → 슬라이드 제목, breadcrumb 색.

## 버리는 것 (`theme.json`의 `warnings`)

자리표시자(제목 제외), 그라데이션·효과, 사각형이 아닌 채운 도형(사각형으로 근사), 채우지 않은 도형, 날짜·쪽 번호 자리표시자.
쪽 번호와 출처는 kit이 직접 그린다.

## 렌더 점검표 (qa.sh 시트에서)

1. 제목 띠와 본문이 겹치는가: kit 본문은 y ≈ 1.3–1.6 in에서 시작한다. 띠가 그보다 길면(경고가 뜬다) 섹션 파일의 y를 내리거나 사용자에게 띠가 얇은 레이아웃을 묻는다.
2. 왼쪽·아래 장식이 그림·단계 글을 가리는가: 가리면 `theme.json`의 `masters.CONTENT.objects`에서 그 항목을 지우거나, 그림 상자를 옮긴다.
3. 강조색이 흐림(흰 막) 위에서 보이는가, 원장 칩 글자가 보이는가.
4. 제목 슬라이드의 제목이 배경 그림과 겹치는가: 제목 슬라이드는 섹션 파일에서 직접 그리므로 위치를 옮긴다.

`theme.json`은 사람이 고쳐도 된다. template.py를 다시 돌리면 덮어쓴다.
