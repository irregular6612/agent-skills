## 1. Frontmatter

키 순서를 그대로 지킨다. `type`이 **맨 끝**이다(교양 노트의 "type 다음 줄 Reading-Status" 규칙과 다르다. 책 노트는 기존 노트를 따른다). 리스트 값은 2칸 들여쓰기 `  - `.

### 서울대 권장도서 100선 책 (`Public/Books/서울대 권장도서 100선/<제목>.md`)

```yaml
---
Reading-Status:
  - ☑️ Not Started
Author:
  - <저자>
Topic:
  - 서울대 권장도서
  - <분야: 한국문학 | 외국문학 | 동양사상 | 서양사상 | 과학기술>
  - <주제어 1>
  - <주제어 2>
Comment: <책 전체를 한 문장으로. "~하는 책이다/장편이다"로 끝나는 경우가 많다>
URL: <기준판 서점 상품 페이지. 보통 YES24 또는 알라딘, 출판사 페이지도 됨>
linked-bases:
  - "[[SNU-100.base]]"
SNU-No: <snu-100.csv 번호, 따옴표 없는 정수>
Start-Date:
End-date:
type: project
---
```

### 100선 밖 책 (`Public/Books/<제목>.md`)

```yaml
---
Reading-Status:
  - ☑️ Not Started
Author:
  - <저자>
Topic:
  - <주제어 1>
  - <주제어 2>
  - <주제어 3>
Comment: <한 문장>
URL: <기준판 서점 상품 페이지>
linked-bases:
  - "[[QA-Books.base]]"
Start-Date:
End-date:
type: project
---
```

값 규칙:
- `Author`: 한국·동아시아 저자는 한국어/한자 표기. 서양 저자는 원어 표기(`Isaac Asimov`)가 조금 더 많고(38) 한국어 표기(`칼 마르크스`)도 흔하다(30). 둘 다 허용. 엮은이가 핵심이면 `- 권택영 (엮음)`처럼 둘째 항목으로 둔다. 미상이면 `- 작자 미상`.
- `Topic`: 100선은 정확히 4개(`서울대 권장도서`, 분야, 주제어 2개). 100선 밖은 주제어 3개가 보통이다.
- `Comment`: 따옴표 없이 한 줄. 줄바꿈 금지.
- `Start-Date`·`End-date`: 새 노트는 비운다. 값은 `YYYY-MM-DD`(따옴표 없음).

## 2. 본문 뼈대

자리표시는 `<…>`. 구분선 `---`은 서지 블록 뒤와 각 H2 앞에 둔다(22개 노트는 "출처" 앞 구분선이 빠졌지만 다수는 있다).

````markdown
# <제목> (<저자 한국어 이름>)

> 공부 방식: 책을 직접 읽지 않고, Claude가 인터넷 조사로 정리한 핵심을 듣고 문답으로 배운다.
> 정리한 날짜: <YYYY-MM-DD> (아직 문답 전)

| 항목 | 내용 |
| --- | --- |
| 제목 | 『<한국어판 제목>』 (<총서·판 정보, 원제 *Original*>) |
| 저자 / 옮긴이 | <저자> / <옮긴이> |
| 출판사·연도 | <출판사>, <YYYY-MM-DD> |
| ISBN | <ISBN-13> |
| 쪽수 | <N>쪽 (<서점>). <다른 서점이 다르게 적으면 그 값도> |
| 원서 | *<원제>*, <원출판사>, <연도>. <판 이력 한두 마디> |
| 서울대 권장도서 100선 | <분야> <번호>번 ([[서울대 권장도서 100선]]) |

> [!note] 판 선택
> <왜 이 판을 기준으로 삼았나: 지금 새 책으로 살 수 있는가, 번역·해설 품질, 다른 판(역자·연도·ISBN)과 어떻게 다른가>

---

## 이 책의 핵심

**한 줄로 먼저: <고등학생이 바로 알아듣는 한두 문장 요지>**

<배경·저자의 문제의식·책의 성격을 2~3문단. 짧은 문장. 낯선 낱말은 괄호로 바로 풀이>

### 꼭 잡아야 할 개념 7개

1. **<개념>**: <두세 문장 설명>
2. …

### 흔한 오해

- **<오해를 굵게 한 문장.>** <왜 아닌지>
- …

### 내 연구와의 연결

<선택. 사용자의 연구와 실제로 이어질 때만. 존재하는 노트만 [[위키링크]]. 없으면 이 소절을 통째로 뺀다>

---

## 목차

<어느 서점(들)의 목차를 옮겼는지, 두 출처가 같은지 다른지 한두 문장>

```
<서점 목차 원문 그대로. 줄바꿈만 정리. 표기 오류도 고치지 않는다>
```

- <출처 사이 차이, 판본별 장 나누기 차이, 확인 못 한 점>

---

## 장별 핵심

"저자가 가장 하고 싶은 말"은 각 장의 논지를 한 문장으로 줄인 해석이며 책 문장을 그대로 인용한 것은 아니다.

### <목차와 같은 장 제목>

> [!quote] 저자가 가장 하고 싶은 말
> <한 문장>

- <핵심 3~5개. 한 줄에 한 생각>

### <다음 장 제목>

…

---

## 문답 기록



---

## 출처와 불확실한 점

- 기준판 서지·목차: [<서점>](<url>), …
- 목차 대조: [<둘째 출처>](<url>)
- 내용 근거: [<백과사전·SEP·출판사 소개·Wikipedia 등>](<url>)
- 원문과 대조하지 못한 것: <목록>
- 추측했거나 자료끼리 다른 것: <목록>
````

100선 밖 책은 서지 표 마지막 줄을 이렇게 쓴다.

```markdown
| 서울대 권장도서 100선 | 없음 ([[서울대 권장도서 100선]]) |
```

관련 100선 책이 있으면 `없음. 관련 노트: [[우파니샤드]](100선 62번), [[서울대 권장도서 100선]]`처럼 단다(바가바드 기타·사피엔스·정의란 무엇인가).

## 3. 장르별 변형 (관찰된 것)

| 장르 | `### 꼭 잡아야 할 …` | `## 장별 핵심`의 단위 | 예 |
| --- | --- | --- | --- |
| 사상·과학 고전 | `개념 7개`(가장 흔함, 6~8개도 있음) | 목차의 장 그대로 `### 1장 …` | 이기적 유전자, 꿈의 해석, 괴델 에셔 바흐 |
| 소설·희곡·시 | `인물과 주제`(번호 목록) | 장이 많거나 제목만 있으면 줄거리 묶음 `### 1. 두 친구 · 홍경애 · …`, 묶은 사실을 머리말에 밝힘 | 삼대, 카인의 후예 |
| 여러 권·전집 | 개념 7개 | 권 단위 `### 제Ⅰ권 …`, 별책도 한 절 | 자본론, 청구야담(권1~권10) |
| 작품집·선집 | 인물과 주제 / 개념 | 부·소설집 `###` 아래 작품 `####`, 각 작품마다 callout | 루쉰전집, 욕망이론 |
| 단편 연작 | 개념 N개 | 단편마다 `###`, 원제·첫 발표 지면을 한 줄 | 아이, 로봇 |

머리말 문장의 "각 장"은 단위에 맞게 바꾼다: 각 권 / 각 묶음 / 각 작품 / 각 편 / 각 단편. 엮은이 해설에는 `> [!quote] 엮은이가 가장 하고 싶은 말`을 쓴 예가 있다(욕망이론).

그 밖의 변형:
- `### 흔한 오해 3가지`처럼 개수를 붙이거나 `### 흔한 오해와 비판`으로 쓴 노트도 있다.
- 두 권을 묶은 책은 서지 표를 `| 항목 | 일리아스 | 오뒷세이아 |`처럼 열을 나눈다.
- 원서 줄 이름은 `원서`·`원서 정보`·`원작`(한국 소설의 연재 정보) 중 맞는 것을 쓴다.
- 판 선택 대신 `> [!note] 번역 용어` 같은 다른 note를 둔 노트도 있다.

## 4. 실제 노트에서 옮긴 예시

`Public/Books/이기적 유전자.md`의 2장 절(그대로 인용):

```markdown
### 2장. 자기 복제자

> [!quote] 저자가 가장 하고 싶은 말
> 생명의 역사는 복제자들의 경쟁사이고, 우리 몸은 그 복제자들이 만든 생존 기계다.

- 출발점은 "안정한 것이 남는다"는 단순한 원리다.
- 아주 먼 옛날 원시 수프에서 우연히 자기 사본을 만드는 분자가 생겼다. 복제 과정의 실수가 변이를 낳았다.
- 오래 살고(수명), 많이 복제되고(다산성), 정확하게 복제되는(정확도) 복제자가 늘어났다.
- 재료를 두고 경쟁하면서 복제자들은 자기를 지키는 껍질, 곧 생존 기계를 만들었다. 오늘날 그 복제자가 유전자이고 생존 기계가 우리다.
```

`Public/Books/서울대 권장도서 100선/삼대.md`의 머리(그대로 인용):

```markdown
# 삼대 (염상섭)

> 공부 방식: 책을 직접 읽지 않고, Claude가 인터넷 조사로 정리한 핵심을 듣고 문답으로 배운다.
> 정리한 날짜: 2026-10-06 (아직 문답 전)
```

## 5. 문답 뒤 갱신 모양

`Public/Books/이기적 유전자.md`·`욕망이론.md`에서 관찰된 모양:

```markdown
> 공부 방식: 책을 직접 읽지 않고, Claude가 인터넷 조사로 정리한 핵심을 듣고 문답으로 배운다.
> 공부한 날짜: 2026-10-05

…

## 문답 기록

### 2026-10-05

-
```

기존 두 노트는 날짜 소절만 있고 내용은 `-` 한 줄로 비어 있다. 문답 내용을 채우는 형식은 아직 관찰된 예가 없다. 사용자가 따로 정하기 전에는 아래처럼 짧게 쓴다.

```markdown
### 2026-10-12

- **Q.** <사용자가 물은 것 한 줄>
  - <답의 요지 한두 줄. 노트 본문과 다르게 정정한 것이 있으면 "정정:"으로>
- **헷갈린 점**: <있으면>
```
