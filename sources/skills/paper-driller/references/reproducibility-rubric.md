# Reproducibility & Reliability Rubric (재현성 및 신뢰도 평가 기준)

논문의 재현 가능성과 결과 신뢰도를 체계적으로 평가하기 위한 기준입니다.

---

## 1. 코드 공개 (Code Availability)

| 등급 | 기준 |
|------|------|
| ✅ 완전 | 전체 코드 공개 + README + 환경 설정 파일 (Docker/conda) |
| ⚠️ 부분 | 핵심 코드만 공개, 또는 코드 공개 예정 (upon acceptance) |
| ❌ 없음 | 코드 미공개, 재현 불가 |

**체크 항목**:
- [ ] GitHub/GitLab 링크 제공 여부
- [ ] 라이선스 명시 여부
- [ ] 환경 재현 파일 (requirements.txt, Dockerfile, conda env) 포함 여부
- [ ] 실행 방법 문서화 여부

---

## 2. 데이터 공개 (Data Availability)

| 등급 | 기준 |
|------|------|
| ✅ 완전 | 전체 데이터셋 공개 또는 공개 데이터셋 사용 + 전처리 코드 |
| ⚠️ 부분 | 샘플 데이터만 공개, 또는 데이터 생성 스크립트 제공 |
| ❌ 없음 | 독점 데이터, 접근 불가 |

**체크 항목**:
- [ ] 데이터셋 다운로드 링크 또는 접근 절차 명시
- [ ] 데이터 전처리 파이프라인 기술 여부
- [ ] 데이터 분할 (train/val/test) 방법 명시
- [ ] 데이터 통계 (크기, 분포, 예시) 제공

---

## 3. 하이퍼파라미터 보고 (Hyperparameter Reporting)

| 등급 | 기준 |
|------|------|
| ✅ 완전 | 모든 하이퍼파라미터 명시 + 탐색 범위 + 선택 근거 |
| ⚠️ 부분 | 주요 하이퍼파라미터만 명시, 탐색 과정 미기술 |
| ❌ 없음 | 하이퍼파라미터 대부분 누락 |

**체크 항목**:
- [ ] 학습률, 배치 크기, 에폭 수 등 기본 하이퍼파라미터 명시
- [ ] 하이퍼파라미터 탐색 방법 (grid/random/Bayesian) 기술
- [ ] 탐색 범위 및 최종 선택값 명시
- [ ] 모델별/실험별 차이가 있는 경우 구분 명시

---

## 4. 실험 환경 보고 (Environment Reporting)

| 등급 | 기준 |
|------|------|
| ✅ 완전 | GPU 사양, 프레임워크 버전, 랜덤 시드, 실행 시간 모두 명시 |
| ⚠️ 부분 | GPU 사양만 명시, 프레임워크 버전 일부 누락 |
| ❌ 없음 | 실험 환경 미기술 |

**체크 항목**:
- [ ] 하드웨어 사양 (GPU 모델, 메모리, 수량) 명시
- [ ] 소프트웨어 버전 (PyTorch, TensorFlow 등) 명시
- [ ] 랜덤 시드 고정 및 보고 여부
- [ ] 학습/추론 시간 보고 여부

---

## 5. 통계적 신뢰도 (Statistical Reliability)

| 등급 | 기준 |
|------|------|
| ✅ 완전 | 다중 실행 (≥3 seeds) + 평균/표준편차 보고 + 유의성 검정 |
| ⚠️ 부분 | 다중 실행이나 표준편차 중 하나만 보고 |
| ❌ 없음 | 단일 실행, 통계 미보고 |

**체크 항목**:
- [ ] 실험 반복 횟수 명시
- [ ] 평균 및 표준편차 (또는 신뢰구간) 보고
- [ ] 통계적 유의성 검정 수행 여부
- [ ] 체리피킹 가능성 (최선 결과만 보고하는지) 검토

---

## 6. 주장별 신뢰도 (Claim Confidence)

각 주요 주장에 대해 근거 수준을 평가:

| 신뢰도 | 기준 | 표기 |
|--------|------|------|
| 🟢 강함 | 다수의 실험 + 통계적 유의성 + ablation으로 뒷받침 | `[confidence: high]` |
| 🟡 보통 | 실험 결과가 있으나 조건부 (특정 설정에서만, 통계 미비) | `[confidence: medium]` |
| 🔴 약함 | 정성적 주장만, 또는 근거 불충분 | `[confidence: low]` |

---

## 7. 읽기 난이도 (Readability Assessment)

| 수준 | 기준 | 대상 독자 |
|------|------|-----------|
| ⭐ 쉬움 | 명확한 구조, 충분한 예시, 배경 설명 풍부 | 해당 분야 입문자 |
| ⭐⭐ 보통 | 분야 기본 지식 필요, 일부 전문 용어 설명 부족 | 분야 대학원생 |
| ⭐⭐⭐ 어려움 | 높은 사전 지식 요구, 수학/이론 밀도 높음 | 분야 전문가 |

---

## 재현성 종합 등급

| 종합 등급 | 기준 |
|-----------|------|
| **A (높음)** | 코드+데이터+하이퍼파라미터+환경 모두 ✅, 통계적 신뢰도 ✅ |
| **B (보통)** | 핵심 요소 대부분 ⚠️ 이상, 치명적 ❌ 없음 |
| **C (낮음)** | 2개 이상 ❌, 재현에 상당한 노력 필요 |
| **D (불가)** | 코드+데이터 모두 ❌, 사실상 재현 불가능 |
