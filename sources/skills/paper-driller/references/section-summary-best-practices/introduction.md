# Introduction Summarization — Best Practices

## Core Principles
1. **Funnel 구조**: 넓은 맥락 → 기존 연구 → 연구 갭 → 본 논문 목표(narrow). 요약도 이 흐름을 보존.
2. **Three pillars**: (a) 무엇이 이미 알려져 있는가(context), (b) 무엇이 빠져 있는가(gap), (c) 본 논문이 무엇을 하는가(contribution).
3. **Motivation의 "왜"**: 단순히 "X를 연구한다"가 아니라 "왜 지금, 왜 이 방식으로"를 포착.
4. **Contribution 문장화**: 논문이 명시한 contribution 목록을 bullet로 보존. 추론·과장 금지.

## Rationale 블록 — `왜 이 연구를 하는가?`
- 핵심 질문 한 문장.
- 기존 접근의 한계 2-4개 표.
- 저자가 내세운 핵심 통찰/가설.

## Anti-patterns
- Related work까지 무분별하게 끌어와 Introduction 범위를 벗어남.
- Gap을 명시하지 않고 contribution만 나열.
- 논문이 선언하지 않은 동기 추가.

## Output Checklist
- [ ] 연구 동기 1-2문장
- [ ] 기존 한계 2+ 항목
- [ ] RQ 또는 핵심 통찰 명시
- [ ] `왜 이 연구를 하는가?` rationale 블록 생성
