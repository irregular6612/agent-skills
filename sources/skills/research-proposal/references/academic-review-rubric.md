# Academic Review Rubric (학술 비평 루브릭)

학술 연구 계획서를 다각도로 평가하기 위한 루브릭입니다. 5개 차원, 각 1-5점, 총 25점 만점. **통과 기준: 20/25 이상**.

---

## 평가 차원

### 1. 논리적 엄밀성 (Logical Rigor) — 1~5점

| 점수 | 기준 |
|------|------|
| 5 | 모든 주장에 논리적 근거가 명확하고, 추론 사슬이 빈틈없이 연결됨. 가정이 명시적으로 분리되어 있으며 각각에 대한 정당화가 존재 |
| 4 | 핵심 주장은 논리적으로 건전하나, 일부 추론에서 약한 연결 고리가 있음. 가정이 대부분 명시적 |
| 3 | 전체적 논리 구조는 있으나, 비약이나 순환 논증이 부분적으로 존재. 일부 가정이 암묵적 |
| 2 | 주요 주장의 논리적 근거가 불충분하거나, 가정과 주장의 경계가 모호 |
| 1 | 논리적 구조가 결여되어 있거나, 핵심 주장에 심각한 논리적 결함 존재 |

**비평 질문**:
- 가설에서 예상 결과로의 추론 과정에 비약은 없는가?
- 각 가정(assumption)이 명시적으로 분리되었는가?
- "A이면 B이다"라는 주장에서, A→B의 인과 경로가 설명되었는가?
- 반례(counterexample)가 고려되었는가?

**세부 평가 항목 (Sub-criteria)**:
- 가설-결과 추론 사슬의 완전성
- 가정(Assumption)과 주장(Claim)의 명시적 분리
- 반례(counterexample) 고려 여부
- 인과 경로 설명의 구체성

---

### 2. 신규성 (Novelty) — 1~5점

| 점수 | 기준 |
|------|------|
| 5 | 완전히 새로운 프레임워크/관점을 제시. 기존 연구와 명확히 차별화되며, 후속 연구를 촉발할 잠재력 |
| 4 | 기존 방법론의 창의적 확장 또는 새로운 도메인 적용. 선행 연구 대비 명확한 기여점 존재 |
| 3 | 부분적으로 새로운 요소가 있으나, 핵심 접근법은 선행 연구와 유사. "incremental" 수준의 기여 |
| 2 | 기존 연구의 minor variation. "So what's new?"에 대한 명확한 답변이 어려움 |
| 1 | 이미 수행된 연구를 반복하거나, 자명한 확장에 불과 |

**비평 질문**:
- 이 연구가 없다면 학계에 어떤 손실이 있는가? (None이면 신규성 부족)
- 선행 연구 X와 비교했을 때, 핵심적 차이는 무엇인가?
- "이것은 이미 [논문]에서 했다"라는 반론에 어떻게 대응할 수 있는가?
- 단순히 데이터셋/모델만 바꾼 것은 아닌가?

**세부 평가 항목 (Sub-criteria)**:
- 선행 연구 대비 핵심 차별점의 명확성
- "So what's new?" 테스트 통과 여부
- 후속 연구 촉발 잠재력
- 학계에 대한 고유 가치 (이 연구가 없으면 어떤 손실?)

---

### 3. 방법론적 건전성 (Methodological Soundness) — 1~5점

| 점수 | 기준 |
|------|------|
| 5 | 연구 질문에 최적화된 방법론. 변수 통제가 완벽하고, 통계적 검정력이 충분하며, 재현 가능성 높음 |
| 4 | 방법론이 대체로 적절하나 minor한 개선 여지 존재. 핵심 위협 요인이 잘 통제됨 |
| 3 | 방법론에 눈에 띄는 약점이 있으나 치명적이지는 않음. 일부 위협 요인이 미통제 |
| 2 | 방법론에 심각한 결함이 있어 결과의 해석 가능성이 제한됨 |
| 1 | 연구 질문에 부적합한 방법론이거나, 근본적 설계 오류 존재 |

**비평 질문**:
- 이 방법론이 연구 질문에 답하기 위한 최선인가? 대안은?
- 내적 타당도를 위협하는 요인(confounders)이 적절히 통제되었는가?
- 통계적 검정력(statistical power)이 충분한가?
- 다른 연구자가 이 실험을 재현할 수 있는가?
- Ablation study가 필요한데 포함되어 있는가?

**세부 평가 항목 (Sub-criteria)**:
- 방법론 비중 30-40% 충족 여부
- 재현 가능성 (다른 연구자가 재현 가능한 수준의 기술)
- 변수 통제의 완전성 (confounders)
- 통계적 검정력(statistical power) 충분성
- Ablation study 포함 여부

---

### 4. 영향력 (Impact Potential) — 1~5점

| 점수 | 기준 |
|------|------|
| 5 | 분야 전체의 관점을 바꿀 잠재력. 이론적 + 실용적 기여 모두 큼. 타 분야로의 파급 효과 예상 |
| 4 | 해당 세부 분야에서 중요한 기여. 실질적 응용 가능성이 높거나 다수의 후속 연구 유발 가능 |
| 3 | 특정 문제 해결에 유용하나, 영향 범위가 제한적 |
| 2 | 학술적 가치는 있으나, 실용적 영향이 미미하고 후속 연구 유발 가능성 낮음 |
| 1 | 영향력이 거의 없거나, 해결하는 문제의 중요도 자체가 낮음 |

**비평 질문**:
- 이 연구 결과가 나오면 누가, 어떻게 활용할 수 있는가?
- 긍정적 결과와 부정적 결과 모두 유의미한 기여가 되는가?
- 5년 후에도 이 연구가 인용될 가능성은?
- 산업/사회적 영향이 있는가?

**세부 평가 항목 (Sub-criteria)**:
- Broader Impacts (사회적 영향) 기술 여부
- 긍정적/부정적 결과 모두의 학술 가치
- 실용적 응용 가능성
- 타 분야 파급 효과

---

### 5. 실현가능성 (Feasibility) — 1~5점

| 점수 | 기준 |
|------|------|
| 5 | 현재 기술/자원으로 즉시 실행 가능. 일정이 현실적이며 리스크 대비책이 구체적 |
| 4 | 약간의 기술적 도전이 있으나 해결 가능한 수준. 리소스 확보 계획이 합리적 |
| 3 | 중간 수준의 기술적/자원적 장벽. 실행 가능하나 상당한 노력 필요 |
| 2 | 높은 기술적 장벽 또는 비현실적 자원 요구. 계획대로 진행될 가능성 낮음 |
| 1 | 현재 기술/자원으로 사실상 실행 불가능하거나, 비현실적 가정에 기반 |

**비평 질문**:
- 필요한 GPU/데이터/인력이 실제로 확보 가능한가?
- 제시된 일정이 현실적인가? (각 단계의 소요 시간 추정이 합리적인가?)
- 주요 리스크에 대한 구체적 대비책(Plan B)이 있는가?
- 기술적으로 해결되지 않은 전제 조건이 있는가?

**세부 평가 항목 (Sub-criteria)**:
- 예산 정당화의 구체성
- 일정의 현실성 (Hofstadter 법칙 반영)
- 예비 결과에 의한 실현 가능성 입증
- Go/No-Go 기준 및 Plan B의 구체성
- 윤리적 승인 계획 (필요시)

## 점수 해석 및 판정

| 총점 | 등급 | 판정 | 조치 |
|------|------|------|------|
| 23-25 | S (탁월) | 즉시 진행 | 최소한의 문구 수정 후 진행 |
| 20-22 | A (우수) | 통과 | 비평 사항 반영 후 진행 |
| 15-19 | B (양호) | 조건부 통과 | 피드백 기반 수정 필요 → idea-concretizer 재실행 |
| 10-14 | C (미흡) | 보류 | 근본적 문제 지적 → 사용자의 대폭 수정 필요 |
| 5-9 | D (부적합) | 반려 | 접근 방식 자체를 재검토 필요 |

## Reviewer Anticipation Checklist (심사자 예상 질문 체크리스트)

비평 시 다음 질문들을 반드시 확인하고, 해당하면 지적:

| # | 예상 질문 | 확인 |
|---|-----------|------|
| 1 | "이 연구가 없다면 학계에 어떤 손실이 있는가?" | ☐ |
| 2 | "이것은 이미 [X 논문]에서 했다"는 반론에 대응 가능한가? | ☐ |
| 3 | 방법론만으로 실험을 재현할 수 있는가? | ☐ |
| 4 | 부정적 결과가 나와도 의미 있는 기여가 되는가? | ☐ |
| 5 | 예산/일정이 현실적인가? | ☐ |
| 6 | 윤리적 고려사항이 적절히 다뤄졌는가? | ☐ |
| 7 | Broader Impacts가 구체적으로 기술되었는가? | ☐ |
| 8 | 예비 결과가 있다면 적절히 활용되었는가? | ☐ |
| 9 | 핵심 가정(assumption)이 명시적으로 분리되었는가? | ☐ |
| 10 | Landmark 논문이 선행 연구에 포함되어 있는가? | ☐ |

## Reviewer 2 페르소나 지침

비평 시 다음 태도를 유지:
- **건설적이되 관대하지 않음**: 약점을 명확히 지적하되, 반드시 개선 방향을 함께 제시
- **"So what's new?"**: 모든 주장에 대해 신규성과 기여를 끊임없이 질문
- **숨은 가정 발굴**: 명시되지 않은 전제를 찾아내어 지적
- **방법론 집착**: 결론보다 과정(방법론)의 건전성에 집중
- **건설적 날카로움**: "이것은 틀렸다"보다 "이것이 성립하려면 X가 필요하다"
