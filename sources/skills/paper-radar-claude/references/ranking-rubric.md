# Paper Radar — Ranking Rubric

랭킹은 Phase 3에서만 쓴다. 이 파일을 읽지 않고 점수를 지어내지 않는다.

## 0. 전제

- 대부분의 후보는 **초록과 메타데이터만** 확보된 상태다. 그 범위에서 판단 가능한 것만 점수화한다.
- 판단 근거가 없으면 점수를 추측하지 말고 `n/a`로 두고 사유를 적는다. `n/a` 축은 분모에서 제외한다.
- 점수는 논문의 학술적 우수성이 아니라 **이 사용자의 학습 가치**를 잰다.

## 1. 축 · 가중치

| # | 축 | 가중치 | 방향 |
|---|---|---:|---|
| 1 | interest fit | 25 | + |
| 2 | pedagogical value | 20 | + |
| 3 | novelty vs Wiki | 15 | + |
| 4 | evidence quality | 12 | + |
| 5 | bridge value | 10 | + |
| 6 | availability | 8 | + |
| 7 | freshness | 10 | + (상한 있음) |
| 8 | risk / overclaim | 15 | **−** (감점) |

총점 계산:

```text
raw   = Σ (score_i / 5) × weight_i        # 축 1–7
score = raw − (risk_score / 5) × 15
```

`n/a` 축이 있으면 그 축의 가중치를 분모에서 빼고 100점 만점으로 재정규화한다. 재정규화했으면 카드에 그 사실을 남긴다.

## 2. 축별 0–5 anchor

### 1. interest fit (25)

| 점수 | 기준 |
|---|---|
| 5 | 활성 트랙의 핵심 키워드가 제목·초록의 주제 자체다 |
| 4 | 트랙 주제를 정면으로 다루되 초점이 조금 다르다 |
| 3 | 트랙과 인접. 응용 사례이거나 부분적으로 겹친다 |
| 2 | 트랙 용어가 쓰이지만 논문의 관심사는 다른 곳에 있다 |
| 1 | 키워드만 스침 |
| 0 | 무관. 카드로 올리지 않는다 |

두 트랙 이상에 걸치면 높은 쪽을 쓰고 카드에 두 트랙을 모두 기록한다.

### 2. pedagogical value (20)

"읽고 나면 이해가 실제로 늘어나는가"를 잰다. 최신성이나 SOTA 여부와 무관하다.

| 점수 | 기준 |
|---|---|
| 5 | 개념을 처음부터 세워 준다. 정의·직관·반례를 함께 준다. 다른 논문을 읽을 렌즈가 된다 |
| 4 | 한 메커니즘을 깊게 설명하고 왜 그렇게 되는지를 다룬다 |
| 3 | 결과는 명확하지만 이해보다는 성능 보고에 가깝다 |
| 2 | 증분 개선. 배경을 이미 아는 사람에게만 의미 있다 |
| 1 | 좁은 엔지니어링 디테일 |
| 0 | 학습 가치 없음 |

survey·tutorial·position 논문은 여기서 높게, freshness에서 낮게 나오는 것이 정상이다.

### 3. novelty vs Wiki (15)

Phase 2의 relation 라벨과 연동한다.

| 점수 | 기준 |
|---|---|
| 5 | Wiki에 관련 노트가 없는 새 영역 |
| 4 | 인접 노트는 있으나 이 각도는 비어 있다 |
| 3 | 관련 노트가 있고 이 논문이 그것을 확장한다 |
| 2 | 기존 노트와 상당 부분 겹친다 |
| 1 | 이미 있는 내용의 재서술 |
| 0 | relation이 `existing`이며 갱신 가치도 없다 |

`follow-up`·`update`는 3 이상을 줄 수 있다. 단 카드에 그 관계를 반드시 밝힌다.

### 4. evidence quality (12)

초록 수준에서 판단 가능한 만큼만 본다.

| 점수 | 기준 |
|---|---|
| 5 | 주장 범위가 좁고 명시적이며 검증 방법과 비교 대상이 초록에 있다 |
| 4 | 실험/증명이 있고 조건이 어느 정도 드러난다 |
| 3 | 결과는 있으나 비교 조건이 불명확하다 |
| 2 | 정성적 주장 위주 |
| 1 | 근거 언급이 거의 없다 |
| 0 | 주장만 있다 |

**초록에 없는 근거를 있다고 가정하지 않는다.** 판단 불가면 `n/a`.

### 5. bridge value (10)

| 점수 | 기준 |
|---|---|
| 5 | Wiki의 서로 다른 노트 3개 이상을 잇는다 |
| 3 | 2개를 잇는다 |
| 1 | 1개에만 붙는다 |
| 0 | 붙일 노트가 없다 |

연결 대상 노트를 실제로 찾아 카드에 링크한다. 찾지 못하면 0이며 "연결 대상 없음"으로 쓴다.

### 6. availability (8)

| 점수 | 기준 |
|---|---|
| 5 | 전문 PDF/HTML + 코드 + 데이터 접근 가능 |
| 4 | 전문 + 코드 |
| 3 | 전문만 |
| 2 | 초록 + venue 페이지 |
| 1 | 초록만 |
| 0 | 초록도 못 구함 (카드로 올리지 않는다) |

접근 가능성은 **실제로 확인한 것**만 센다. arXiv ID가 있으니 전문이 있을 것이라는 추정은 4가 아니라 3이다.

### 7. freshness (10) — 상한 있음

| 점수 | 기준 |
|---|---|
| 5 | 최근 30일 |
| 4 | 최근 90일 |
| 3 | 최근 1년 |
| 2 | 1–3년 |
| 1 | 3–7년 |
| 0 | 7년 초과 |

**freshness 지배 방지 규칙 (필수):**

1. freshness 가중치는 10을 넘길 수 없다. `config.yaml`에서 사용자가 올리더라도 10으로 clamp하고 clamp했다고 보고한다.
2. 최종 카드가 전부 freshness ≥ 4면, `curriculum` pool의 최고점 후보 1장을 강제로 포함한다 (다른 카드 1장을 밀어낸다).
3. freshness 0–1이라는 이유만으로 후보를 탈락시키지 않는다.

### 8. risk / overclaim (15, 감점)

높을수록 **나쁘다**.

| 점수 | 기준 |
|---|---|
| 5 | 검증 불가한 대주장. "understanding/consciousness/AGI 달성" 류 |
| 4 | 표면적 생물학 비유 (`mapping_depth: metaphorical`) |
| 3 | 근거 대비 일반화 범위가 과하다 |
| 2 | 단일 모델·단일 벤치마크 결과를 일반 법칙처럼 서술 |
| 1 | 경미한 과장 |
| 0 | 주장 범위가 근거와 맞다 |

`brain-analogy` 트랙은 `mapping_depth`를 여기에 연결한다.

```text
metaphorical    → risk 4
functional      → risk 2
representational→ risk 2
mathematical    → risk 1
empirically-tested → risk 0
```

## 3. tie-break

동점이면 순서대로:

1. `pedagogical value`가 높은 쪽
2. `novelty vs Wiki`가 높은 쪽
3. `bridge value`가 높은 쪽
4. `pool` 다양성을 늘리는 쪽 (`curriculum` > `graph` > `frontier`)
5. 오래된 쪽 (curriculum 편향을 의도적으로 유지)

freshness는 tie-break에 쓰지 않는다.

## 4. 피드백 반영

`feedback.yaml`의 신호는 원점수를 바꾸지 않고 **후처리 보정**으로 적용한다.

| 신호 | 보정 |
|---|---|
| 같은 트랙 `드릴` 3회 이상 | interest fit +0.5 (상한 5) |
| 같은 트랙 `제외` 3회 이상 | interest fit −1.0 (하한 0) |
| 특정 저자·lab을 반복 선택 | +2점 (총점) |
| 이유 있는 `제외`의 키워드와 일치 | −5점 (총점), 카드에 사유를 함께 표시 |

**exploratory 슬롯 후보에는 이 보정을 적용하지 않는다.** filter bubble 방지가 우선이다.

## 5. 기록

각 카드의 점수 근거를 `state.json`의 해당 `radar_id` 아래에 남긴다.

```json
{
  "scores": {"interest_fit": 5, "pedagogical": 4, "novelty": 3,
             "evidence": "n/a", "bridge": 3, "availability": 3,
             "freshness": 5, "risk": 1},
  "renormalized": true,
  "total": 78.4,
  "notes": "evidence n/a — 초록에 비교 조건 없음"
}
```
