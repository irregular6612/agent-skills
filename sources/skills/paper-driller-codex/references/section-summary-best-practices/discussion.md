# Discussion Summarization — Best Practices

## Core Principles
1. **Interpret, don't repeat**: Results의 숫자를 복사하지 말고, 그것이 **무엇을 의미하는지**를 요약.
2. **Triad**: (a) 주요 발견의 의미, (b) 선행 연구와의 비교/정합, (c) 한계 + 향후 방향.
3. **Limitations — 저자가 인정한 것 + 독자가 식별 가능한 것**: 두 범주를 구분해 표기.
4. **Implications은 practical vs theoretical로 분리**: 응용 가능성과 이론적 기여를 혼동하지 않음.
5. **Future work은 limitations와 연결**: 각 future work 제안이 어떤 한계를 해결하는지 짝지음.

## Sub-subsection — `이론적 의의`
- 2-3개 항목. 각 항목은 "이 연구가 분야에 새로 기여한 이론적 포인트".
- 응용·실무 임팩트는 별도.

## Discussion Points (별도 블록)
- **논쟁점**: 커뮤니티에서 논쟁 가능한 주장.
- **검증 필요 가정**: 후속 실험으로 검증돼야 할 전제.
- **후속 연구**: 자연스러운 다음 단계.

## Anti-patterns
- Results 재나열.
- "향후 연구가 필요하다" 한 줄로 퉁치기.
- 한계를 과소평가하거나 과장.

## Output Checklist
- [ ] 주요 발견의 의미 서술
- [ ] 한계 2+ 항목
- [ ] 향후 방향 1+ 항목, 한계와 연결
- [ ] `이론적 의의` sub-subsection 2-3 항목
- [ ] Discussion Points (논쟁점/검증 가정/후속) 각 1+
