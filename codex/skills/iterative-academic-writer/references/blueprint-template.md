# Blueprint Template

섹션별 구조 공식은 `section-writing-guide.md`를 참조해 각 섹션의 핵심 메시지를 채운다.

```markdown
# Blueprint

## 문서 정보

- **유형**: [논문 섹션 / 연구 제안서 / SoP·학업계획서 / 기술 문서]
- **주제**: [구체적 주제]
- **목표 독자**: [학술 논문 독자 / 일반 독자 / 기술자]

---

## 전체 구조

### [섹션 1 이름]

**핵심 메시지**: [이 섹션이 전달해야 할 핵심 한 문장]

### [섹션 2 이름]

**핵심 메시지**: [...]

---

## 정의 목록

| 용어   | 정의 초안                                                                          | 첫 등장 섹션 | Fact Base ID |
| ------ | ---------------------------------------------------------------------------------- | ------------ | ------------ |
| MemGen | MemGen은 latent memory token을 생성하여 LLM 추론을 보강하는 프레임워크이다.        | 3.1          | F3           |
| LTPO   | LTPO는 inference 시 모델 가중치를 변경하지 않고 latent 표현만 최적화하는 기법이다. | 3.4          | F5           |

---

## 비교-대조 목록

| 기존 방법   | 제안 방법 | 비교 포인트                        | 등장 섹션 |
| ----------- | --------- | ---------------------------------- | --------- |
| RAG         | MemGen    | 외부 DB 검색 vs 내부 latent 생성   | 3.1       |
| Fine-tuning | LTPO      | 파라미터 업데이트 vs latent 최적화 | 3.4       |

---

## 문단 흐름 (두괄식 첫 문장)

### [섹션 1]

1. **"[핵심 주장 첫 문장]"**
   → [이 문단에서 다룰 내용]
   → WHY (IS1): [왜 이 방법/주장이 필요한가 — "X의 한계로 인해 Y가 필요하다"]
   → Causal chain (IS2): [A이므로 B, 따라서 C — 인과 구조 초안]
   → 다음 문단 접속어: [또한 / 반면 / 따라서 / 구체적으로]

2. **"[핵심 주장 첫 문장]"**
   → [이 문단에서 다룰 내용]
   → WHY (IS1): [...]
   → Causal chain (IS2): [...]
   → 다음 문단 접속어: [...]
```
