# Abstract Summarization — Best Practices

## Core Principles
1. **Five-beat structure**: background → objective → methods(1 line) → key results(수치 포함) → conclusion. 전체 3-5문장.
2. **Numbers over adjectives**: "크게 개선" 금지. "+3.2 F1 (Table 2)" 처럼 구체 수치 + 출처.
3. **Self-contained**: 논문 나머지를 읽지 않아도 의사결정 가능해야 함 (읽을 가치 판별).
4. **Compressed**: 초록은 이미 압축된 텍스트. 요약할 때 원문 명사구를 보존하되 수동태/군더더기 제거.

## Anti-patterns
- "본 논문은 ~을 제안한다" 같은 선언문만 반복.
- motivation 없이 method만 나열.
- conclusion 생략.
- 논문이 주장하지 않은 함의 추가.

## Output Checklist
- [ ] 3-5문장 요약에 background/objective/method/results/conclusion 포함
- [ ] 선언적 contribution 2-3 bullet (동사로 시작)
- [ ] 원문 초록의 핵심 수치가 누락되지 않음
